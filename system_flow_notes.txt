[2. TRIGGER & INPUT] (เข้าได้ 2 ทาง)
  ├─ ทางเสียง: ได้ยิน "Jarvis" ──▶ Dynamic Island เด้งเปิด (โหมด Listening) ──▶ Faster-Whisper แปลงเสียงเป็น Text
  └─ ทางพิมพ์: กด Alt+Space (หรือสั่งเปิดแชท) ──▶ Overlay Chat เด้งเปิด ──▶ ผู้ใช้พิมพ์ข้อความแล้วกด Enter

[3. BRAIN & EXECUTION]
  └─ Text ส่งเข้า core/brain.py (Gemini API: gemini-2.5-flash / gemini-4-hydrogen)
       ├─ Dynamic Island / Overlay เปลี่ยนสถานะเป็น "Thinking..."
       ├─ กรณีตอบทั่วไป ──▶ ส่งข้อความตอบกลับทันที
       ├─ กรณีเรียก MCP / Local Tool ──▶ รันฟังก์ชันใน core/tools.py หรือ mcp_manager.py ──▶ ส่งผลกลับให้ Gemini สรุป
       └─ กรณีสั่งงาน Antigravity ──▶ เรียก antigravity_bridge.py:
            1. ดึงหน้าต่าง Antigravity ขึ้นมาโฟกัส + เปิดช่อง Agent Chat

            3. รัน Thread เฝ้าไฟล์ผลลัพธ์ ──▶ เมื่อ Antigravity ทำเสร็จ ──▶ ดึงเนื้อหามาให้ Gemini สรุปสั้นๆ

[4. OUTPUT & RETURN TO IDLE]
  ├─ Dynamic Island เปลี่ยนสถานะเป็น "Speaking..." ──▶ Edge-TTS พูดสรุปใจความสำคัญ

  └─ เมื่อพูดจบ ──▶ Dynamic Island หดปิดกลับอัตโนมัติ (ส่วน Overlay Chat เปิดค้างไว้จนกว่าผู้ใช้จะกด Esc หรือสั่งปิด)
